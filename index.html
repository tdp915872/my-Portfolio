About Me

저는 작은 기능도 서비스 흐름으로 이해하려고 합니다.

저는 컴퓨터정보공학부 3학년으로, 웹 개발과 클라우드 기반 서비스 구조에 관심이 있습니다. 수업에서 배우는 바이브 코딩을 활용하여 요구사항을 정리하고, 화면과 기능을 나누며, 실제 서비스처럼 동작하는 포트폴리오를 만들고자 합니다.

이 프로젝트에서 가장 중요하게 생각하는 부분은 “누가 어떤 기능을 사용할 수 있는가”입니다. 그래서 비로그인 방문자, 로그인 방문자, 관리자 역할을 나누고 각 역할마다 접근 가능한 기능을 다르게 설계했습니다.

앞으로는 이 프론트엔드 프로토타입을 Spring Boot 백엔드, MySQL 기반 RDS, 이미지 저장용 S3, 서버 배포용 EC2와 연결하여 완성도 있는 동적 웹 서비스로 발전시키는 것이 목표입니다.
